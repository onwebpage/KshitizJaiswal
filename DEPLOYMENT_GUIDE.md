# Deployment Guide - Kshitiz Jaiswal Website

## Deploy to Render

### Step 1: Prepare Your Repository
1. Ensure all files are committed to your Git repository
2. Make sure `render_requirements.txt` and `render.yaml` are in your root directory

### Step 2: Create Render Account
1. Go to [Render.com](https://render.com)
2. Sign up or log in with your GitHub account
3. Connect your repository

### Step 3: Deploy with Render YAML
1. In Render dashboard, click "New +"
2. Select "Blueprint"
3. Connect your repository
4. Render will automatically detect the `render.yaml` file
5. Review the configuration and deploy

### Step 4: Configure Environment Variables
Set these environment variables in Render:

**Required:**
- `DATABASE_URL` - Automatically set by Render PostgreSQL
- `SESSION_SECRET` - Auto-generated by Render
- `FLASK_ENV` - Set to "production"

**Optional (for payment functionality):**
- `RAZORPAY_KEY_ID` - Your Razorpay API key
- `RAZORPAY_KEY_SECRET` - Your Razorpay secret key

### Step 5: Database Setup
1. The PostgreSQL database will be created automatically
2. Database tables will be created on first startup
3. You can run the data migration script to populate initial content

### Manual Deployment (Alternative)

If you prefer manual setup:

1. **Create Web Service:**
   - Service Name: `kshitiz-jaiswal-website`
   - Environment: `Python 3`
   - Build Command: `pip install -r render_requirements.txt`
   - Start Command: `gunicorn --bind 0.0.0.0:$PORT main:app`

2. **Create PostgreSQL Database:**
   - Database Name: `kshitiz_website`
   - Plan: Free tier

3. **Connect Database:**
   - Copy DATABASE_URL from database to web service environment variables

### Post-Deployment Steps

1. **Admin Access:**
   - Visit `/admin` to set up admin credentials
   - Default admin username can be configured in the admin panel

2. **Content Management:**
   - Use the admin panel to manage reels, opinions, and resources
   - Upload images and configure site content

3. **Payment Setup (Optional):**
   - Configure Razorpay credentials in admin panel
   - Test payment functionality

### Troubleshooting

**Common Issues:**
- Build fails: Check `render_requirements.txt` for correct package versions
- Database connection: Ensure DATABASE_URL is set correctly
- Static files: Ensure upload directories are created properly

**Logs:**
- Check Render service logs for detailed error messages
- Enable debug mode temporarily if needed

### File Structure for Deployment
```
.
├── render.yaml              # Render deployment configuration
├── render_requirements.txt  # Python dependencies
├── main.py                  # Application entry point
├── app.py                   # Flask application setup
├── routes.py                # Application routes
├── models.py                # Database models
├── forms.py                 # WTForms definitions
├── utils.py                 # Utility functions
├── static/                  # Static assets (CSS, JS, images)
├── templates/               # Jinja2 templates
└── data/                    # JSON data files (for migration)
```

### Production Considerations

1. **Security:**
   - SESSION_SECRET is auto-generated
   - HTTPS is enabled by default on Render
   - Database credentials are managed securely

2. **Performance:**
   - Gunicorn WSGI server for production
   - ProxyFix middleware for proper headers
   - Database connection pooling enabled

3. **Monitoring:**
   - Use Render's built-in logs and metrics
   - Set up health checks if needed

### Custom Domain (Optional)

1. In Render dashboard, go to your service
2. Navigate to "Settings" > "Custom Domains"
3. Add your domain and follow DNS configuration instructions
