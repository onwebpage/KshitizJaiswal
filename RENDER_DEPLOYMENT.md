# Render Deployment Guide

## Quick Deployment Steps

Your website is now ready to deploy on Render! Just follow these steps:

### 1. Push Your Code to GitHub
Make sure all your latest changes are pushed to your GitHub repository.

### 2. Create a New Web Service on Render
1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click **"New +"** button → Select **"Web Service"**
3. Connect your GitHub repository
4. Render will automatically detect the `render.yaml` file

### 3. Configure Environment Variables
When creating the service, you'll need to set these environment variables:

#### Required Environment Variables:
- **SESSION_SECRET** - Auto-generated by Render (already configured in render.yaml)
- **DATABASE_URL** - Auto-configured from the database (already configured in render.yaml)

#### Optional Environment Variables (for full functionality):

**Clerk Authentication (for user login/signup):**
- `CLERK_PUBLISHABLE_KEY` - Get from [Clerk Dashboard](https://dashboard.clerk.com/)
- `CLERK_SECRET_KEY` - Get from [Clerk Dashboard](https://dashboard.clerk.com/)

**Admin Access:**
- `ADMIN_USERNAME` - Your admin username (defaults to 'admin' if not set)
- `ADMIN_PASSWORD` - Your admin password (defaults to 'kshitiz2025' if not set)

**Razorpay Payment Integration (for subscriptions):**
- `RAZORPAY_KEY_ID` - Get from [Razorpay Dashboard](https://dashboard.razorpay.com/)
- `RAZORPAY_KEY_SECRET` - Get from [Razorpay Dashboard](https://dashboard.razorpay.com/)

### 4. Deploy
1. Click **"Create Web Service"**
2. Render will automatically:
   - Create a PostgreSQL database
   - Install dependencies from `render_requirements.txt`
   - Run database migrations
   - Start your application

### 5. Access Your Website
Once deployment completes, Render will provide a URL like:
`https://kshitiz-jaiswal-website.onrender.com`

## Important Notes

### Database
- Render will automatically create a PostgreSQL database
- All database tables will be created automatically on first run
- The free tier database will spin down after inactivity

### Free Tier Limitations
- The free tier service will spin down after 15 minutes of inactivity
- First request after spin-down may take 30-60 seconds
- Database has storage limits on free tier

### Admin Access
After deployment, access the admin panel at:
`https://your-app.onrender.com/admin/login`

Default credentials (if environment variables not set):
- Username: `admin`
- Password: `kshitiz2025`

**⚠️ IMPORTANT:** Change these credentials by setting the environment variables in Render!

### Clerk Authentication Setup
If you want user authentication:
1. Create a free account at [Clerk](https://clerk.com/)
2. Create a new application
3. Copy the Publishable Key and Secret Key
4. Add them as environment variables in Render
5. Redeploy the service

## Troubleshooting

### Build Fails
- Check that `render_requirements.txt` has all dependencies
- Verify Python version compatibility

### Database Connection Errors
- Ensure the database service is created and linked in `render.yaml`
- Check that DATABASE_URL is properly configured

### Application Not Starting
- Check the Render logs for specific error messages
- Verify all required environment variables are set

### After Deployment Changes
If you make changes to environment variables:
1. Go to your service on Render
2. Click **"Manual Deploy"** → **"Deploy latest commit"**
3. Wait for deployment to complete

## File Structure for Deployment

These files are critical for Render deployment:
- ✅ `render.yaml` - Render configuration (defines services and database)
- ✅ `render_requirements.txt` - Python dependencies
- ✅ `main.py` - Application entry point
- ✅ `app.py` - Flask app initialization
- ✅ `models.py` - Database models
- ✅ `routes.py` - Application routes

All files are properly configured and ready for deployment!
